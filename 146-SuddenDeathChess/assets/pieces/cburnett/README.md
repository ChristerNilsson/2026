# Cburnett pieces

Artwork by Colin M. L. Burnett, distributed under GPL-2.0-or-later.

Source: https://github.com/lichess-org/lila/tree/master/public/piece/cburnett

Lichess attribution: https://github.com/lichess-org/lila/blob/master/COPYING.md

The twelve SVG source files were downloaded on 2026-09-28 without changes.
The corresponding transparent 64 × 64 PNG files were rendered using
resvg-py 0.5.0 (`svg_to_bytes(svg_path=..., width=64, height=64)`).
The application loads these PNGs directly with Tkinter; resvg-py is only
needed to regenerate them, not to run the game.

The license text is included in [COPYING.txt](COPYING.txt).
