# Man ska navigera genom denna bana

Bra att kunna välja mellan två banor. 
Läs in vald bana och visa texten i en textarea.
Man ska kunna uppdatera visningen efter redigering av textarean.

Starten är START och man ska till TARGET  

Skapa index.html och visa banan  

Av indenteringen framgår vilka drag som är tillåtna.

TARGET tar emot alla från raden ovan.

Visa inte bara aktuella val, visa även kommande möjliga drag, dvs hela banan inkl TARGET.
Visa hela banan.
Förskjut nivåerna så att det blir tydligt var man kan gå.
Av txt-filerna framgår indentering. Man ska klicka i grafen.
Markera aktuell nod. START är startnoden

Visa banan samt var spelaren befinner sig och tillåt bara möjliga drag.
Personen ska klicka sig fram till TARGET
